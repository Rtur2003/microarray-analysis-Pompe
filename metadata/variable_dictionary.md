# Variable Dictionary

| column                 | description                                              |
|------------------------|----------------------------------------------------------|
| sample_id              | GEO sample accession (e.g., GSM947461)                   |
| group                  | Phenotype group: Control or Pompe                        |
| filename               | CEL file name associated with the sample (LFS-tracked)   |
| batch                  | Batch identifier from GEO                                |
| sex                    | Biological sex (M/F)                                     |
| rin                    | RNA integrity number (if available)                      |
| is_melas               | `TRUE` if sample flagged for MELAS sensitivity analysis  |
| age_at_baseline_month  | Age at sampling in months                                |
| special_case           | 1 if sample flagged for special handling in GEO metadata |
